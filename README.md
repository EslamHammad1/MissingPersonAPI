The **Missing Person API** is a backend RESTful service built with **C# and .NET**, designed to manage and search missing person records efficiently.

It provides secure endpoints for **creating, retrieving, updating, deleting, and searching** missing person information.

---

## 🚀 What This Project Does

- Stores missing person records in a structured database
- Allows searching by multiple criteria (name, age, location, status, etc.)
- Supports full CRUD operations
- Exposes clean and well-structured REST APIs
- Designed to be scalable and easy to extend

---

## 📌 Features

- RESTful API design
- CRUD operations for missing persons
- Advanced search & filtering
- Input validation
- Global exception handling
- Clean and maintainable architecture
- Ready-to-use backend template
